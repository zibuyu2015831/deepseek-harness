# 已归档的计划

> 目录规则见 [`plans/index.md`](../index.md)。

**进入判据**：计划被放弃、被新计划取代，或它依赖的前提已不再成立。

## 本目录是只读的

归档内容**不得编辑，也不得当作当前权威**。它保留的是"当时为什么这么打算"，而不是"现在应该怎么做"。

这条与仓库对 [`.agents/notes/archived/`](../../../.agents/notes/README.md#archiving-and-deletion) 的处理一致，理由也一样：归档文档读起来和现行文档一样自信，唯一能区分它们的是所在目录。归档时**不要**在正文加"已废弃"之类的状态标注——目录本身就是状态。
