# 排障案例索引

> 目录规则见 [`knowledge/index.md`](../index.md)。

**先去 [`troubleshooting.md`](../../troubleshooting.md)**——那里是症状到上游事实源的反查表，覆盖面更广。本目录只放它答不出的：**实际撞上过、且原因不显然**的具体案例。

## 一条案例记录什么

- **症状** — 你看到的原始报错或现象，逐字粘贴，不要复述。搜索时靠的就是这段原文。
- **复现条件** — 平台、profile/bundle、相关配置。这个仓库跨 macOS/Linux/Windows，很多故障是平台相关的。
- **根因** — 指向具体的 `path:line` 或上游文档章节。
- **解法** — 实际做了什么。
- **验证** — 怎么确认修好了。

**如果根因落在上游文档写错上**，同时登记到根目录的 [`UPSTREAM_DOC_ISSUES.md`](../../../UPSTREAM_DOC_ISSUES.md)。
